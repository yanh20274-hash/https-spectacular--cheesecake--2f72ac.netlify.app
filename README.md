# 청도 이동상점마켓

청도 마을 주민이 필요한 상품을 미리 주문하면 마을 이장님 또는 이동상점 담당자가 확인하고, 농협에서 상품을 준비해 이동상점 차량에 싣고 방문하는 흐름을 보여주는 반응형 웹 앱 데모입니다. 주민은 이동상점 방문일에 마을에서 상품을 받아갈 수 있으며, 차량에 실어 온 상품을 현장에서 직접 구매하는 상황도 안내합니다. 별도 배송비는 없습니다.

## 실행

`index.html`을 브라우저에서 열거나 정적 사이트 호스팅에 배포하면 됩니다. 빌드 도구나 별도 의존성은 필요하지 않습니다.

## 포함된 기능

- 상품 검색, 카테고리 필터, 가격·인기순 정렬과 찜하기
- 장바구니 추가 및 수량 변경, 상품 합계 계산 (배송비 없음)
- 장바구니 브라우저 저장
- 마을·연락처를 입력해 주문 요청을 등록하는 데모
- 담당자 화면에서 주문 요청을 확인 처리하는 데모
- 이동상점 방문 일정 및 마을 현장 구매 안내
- 모바일·태블릿·데스크톱 반응형 레이아웃

## 실제 운영 전 참고

상품·가격·마을 일정은 예시입니다. 주문 요청과 담당자 확인 내역은 현재 해당 브라우저의 `localStorage`에만 저장되므로, 서로 다른 주민·이장님·기사님 기기 간에 공유되지 않으며 실제 농협 발주나 주문 전송도 되지 않습니다. 여러 사용자가 실시간으로 주문을 공유하려면 인증, 데이터베이스, 권한별 담당자 화면과 알림을 포함한 백엔드 연동이 필요합니다. 실제 수령·결제 방법과 상품 재고/준비 절차를 확정한 뒤 안내 문구를 맞춰 주세요.
