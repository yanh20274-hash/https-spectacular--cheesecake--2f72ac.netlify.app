# 청도 이동상점마켓

청도의 지역 농산물·특산물·동네 상점 상품을 구경하고 장바구니에 담아 주문 정보를 확인하는 반응형 웹 앱 데모입니다. 마���별 이동상점 일정 섹션도 포함되어 있습니다.

## 실행

`index.html`을 브라우저에서 열거나 정적 사이트 호스팅에 배포하면 됩니다. 빌드 도구나 별도 의존성은 필요하지 않습니다.

## 포함된 기능

- 상품 검색, 카테고리 필터, 가격·인기순 정렬
- 상품 찜하기
- 장바구니 추가 및 수량 변경, 합계와 배송비 계산
- 장바구니를 브라우저에 저장해 새로고침 후에도 유지
- 주문 정보 입력 화면 (데모: 실제 주문·결제는 전송하지 않음)
- 청도 마을별 이동상점 일정 안내
- 모바일·태블릿·데스크톱 반응형 레이아웃

## 실제 서비스에 연결하기 전에

화면에 포함된 상품, 가격, 생산자, 방문 일정은 데모용 예시입니다. 실제 판매 정보를 확인해 교체하고, 주문 저장·재고 관리·배송 정책·결제·고객 정보 보호를 위한 백엔드와 개인정보 안내를 별도로 연결해 주세요.
